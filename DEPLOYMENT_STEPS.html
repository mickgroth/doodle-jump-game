🚀 Deploy Your Doodle Jump Game

Follow these steps to get your game online in 10 minutes!

1
Create GitHub Account 2 min
  • Go to github.com
  • Click Sign up (if you don't have an account)
  • Follow the registration process
  • Verify your email address
2
Create New Repository 2 min
  • Click the + icon in the top-right corner
  • Select New repository
  • Repository name: doodle-jump-game (or any name you prefer)
  • Description: "A fun Doodle Jump clone"
  • Select Public (required for free GitHub Pages)
  • Click Create repository
3
Upload Your Game Files 3 min

On your new repository page:

  • Click Add file → Upload files
  • Drag and drop these files from your folder:
  • index.html - Main game page
  • game.js - Game logic
  • style.css - Styling
  • README.md - Description
  • Scroll down and click Commit changes
  • Wait for the upload to complete (green checkmark)
4
Enable GitHub Pages 2 min
  • In your repository, click Settings (top menu)
  • Scroll down and click Pages (left sidebar)
  • Under Source, select:
    • Branch: main (or master)
    • Folder: / (root)
  • Click Save
  • Wait 2-3 minutes for deployment to complete
💡 Tip: The page will show you the URL where your game will be published. Bookmark it!
5
Get Your Game URL! 1 min

Your game will be live at this URL:

https://YOUR-USERNAME.github.io/doodle-jump-game/

Replace YOUR-USERNAME with your actual GitHub username.

🎮 Test it: Open the URL in your browser and play the game to make sure everything works!

🎉 Congratulations!

Your game is now live on the internet!
