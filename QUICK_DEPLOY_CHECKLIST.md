# ✅ Quick Deploy Checklist

Copy this checklist and check off each step as you go!

## Before You Start
- [ ] You have all 4 files ready: `index.html`, `game.js`, `style.css`, `README.md`
- [ ] You have a GitHub account (or can create one)

## Deployment Steps

### 1. Create Repository
- [ ] Go to github.com and log in
- [ ] Click the "+" icon → "New repository"
- [ ] Name it: `doodle-jump-game` (or your preferred name)
- [ ] Set to **Public**
- [ ] Click "Create repository"

### 2. Upload Files
- [ ] Click "Add file" → "Upload files"
- [ ] Drag all 4 files into the upload area
- [ ] Click "Commit changes"

### 3. Enable GitHub Pages
- [ ] Go to "Settings" tab
- [ ] Click "Pages" in left sidebar
- [ ] Under "Source", select branch: **main**
- [ ] Click "Save"
- [ ] Wait 2-3 minutes

### 4. Test Your Game
- [ ] Copy your URL: `https://YOUR-USERNAME.github.io/doodle-jump-game/`
- [ ] Open it in a browser
- [ ] Play the game to verify it works!

### 5. Share With Friends
- [ ] Send the URL to your friends
- [ ] Celebrate! 🎉
